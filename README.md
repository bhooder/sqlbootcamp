# SQL Claims Lab

An interactive, beginner-first SQL course for data analysis, built on a small insurance company's database (policyholders, policies, claims).

- 16 lessons, from "what is a table" to joins, CASE banding, rates, and claim frequency/severity
- Every lesson ends with a business question that is checked automatically
- A workspace laid out like real SQL tools: database explorer, query editor, results grid, messages log
- A sandbox for free-form analysis

Runs entirely in the browser using [sql.js](https://github.com/sql-js/sql.js) (SQLite compiled to JavaScript). No server, no install.
